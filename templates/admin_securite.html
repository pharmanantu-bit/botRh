Activer la 2FA — 3 étapes (sur PythonAnywhere)

  1. Installer les librairies (console Bash) :
    pip3 install --user pyotp qrcode
  2. Générer une clé secrète :
    python3 -c "import pyotp; print(pyotp.random_base32())"
    copie la valeur affichée.
  3. Ajouter au .env (onglet Files) :
    ADMIN_TOTP_SECRET=<la clé générée>
    puis onglet Web → Reload.

Reviens ensuite sur cette page : un QR code s'affichera pour l'ajouter à ton application.

🛡️ Tant que ADMIN_TOTP_SECRET n'est pas défini, la connexion reste au mot de passe seul (rien n'est cassé). La 2FA ne s'active qu'une fois la clé posée.
